# Security Policy

The Federal Republic of Kabylia takes security seriously across its digital public infrastructure and official resources.

## Reporting a vulnerability

If you believe you have discovered a security issue in a repository under this organization, please report it privately and responsibly.

Use the GitHub Security Advisory workflow for the affected repository, or contact the maintainers through the official organization channels if a private report is required.

Please avoid public disclosure until the issue has been assessed and addressed.

## Response expectations

We will do our best to:

- acknowledge valid reports promptly,
- assess severity and impact,
- coordinate a fix or mitigation when appropriate, and
- communicate clearly with the reporter throughout the process.

## Scope

This policy applies to official repositories maintained under the Federal Republic of Kabylia organization.
